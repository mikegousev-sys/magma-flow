# Гидродинамика шлака в жёлобе и поправки к расходу

Исходные данные: чертёж Б-Б (медный жёлоб R150, стенки 22.5°, глубина 321 мм от фланца
кожуха), А-А (уклон 6°21′, проверен по наклону линий чертежа: 6.1–6.4°), хим. состав шлака
ПВП (июнь 2026), минералогия ПР-20 «Шлак ПВП-2 на ОЭП-4», записи 19.09 и 01.10.
Расчёт: `analysis/hydraulics.py`, результаты `hydraulics.json`.

## Свойства расплава (оценка)

| величина | значение | основание |
|---|---|---|
| плотность шлака, 1250 °C | 3480–3515 кг/м³ (±2%) | парциальные молярные объёмы (Mills–Keene), состав ПВП; в расчётах стояло 3400 |
| температурный коэффициент плотности | −0.1% на 10 K | там же |
| вкрапленный штейн | 1–4% масс. (0.7–3% об.), до ~10% в пробах с Ni > 2% | баланс Ni (шлак 0.7–3.2%, штейн ~22%) и сульфидные фазы минералогии (~0.8% масс. + Fe-фаза 2.6%) |
| плотность эмульсии | +0.3…+1.5% к шлаку (до +3.5% при 10% штейна) | смешение по объёму, штейн 4800–5500 кг/м³ |
| вязкость жидкого шлака, 1250 °C | 0.1–0.5 Па·с (типично для фаялитовых шлаков Fe/SiO2 ≈ 1.1) | не измерена; около ликвидуса и при выделении магнетита (Fe3O4 до 7%) растёт в разы |
| чувствительность вязкости к T | ~10% на 10 K | Аррениус, E ≈ 200 кДж/моль |
| осаждение капель штейна | 0.1 мм: 0.03 мм/с; 1 мм: ~3 мм/с при μ = 0.3 Па·с | Стокс; за 5–10 с пролёта жёлоба эмульсия не расслаивается |

## Режим течения (записи 01.10, гарнисаж 0)

| | 21:04:42 | 20:59:53 |
|---|---|---|
| скорость на оси | 2.08 м/с | 1.81 м/с |
| уровень / ширина зеркала | 52 / 227 мм | 72 / 256 мм |
| A, R_h | 82 см², 32 мм | 130 см², 43 мм |
| средняя скорость U | 1.16–1.51 м/с | 1.05–1.37 м/с |
| Fr = U/√(g·A/B) | 1.9–2.5 | 1.5–1.9 |
| Re = ρU·4R_h/μ при μ 0.2 / 0.5 Па·с | 2500–3300 / 1000–1300 | 3000–4000 / 1200–1600 |

- Поток **бурный** (Fr > 1): уровень задаётся местно, подпора снизу нет; при Fr ≈ 2 возможны
  катящиеся волны — расход нужно считать по сериям (произведение мгновенных A·u), а не как
  произведение средних.
- По Re — **переходная область**: точный режим зависит от вязкости, т. е. от температуры и
  содержания кристаллов.
- **Разгон в кадре**: скорость в правой (нижней по течению) половине кадра выше левой на
  −1…+5% (зависит от градиента масштаба вдоль кадра), без трения было бы +10…12%. Поток близок к равновесию «сила тяжести = трение»,
  измерение в одном сечении представительно.
- **Сопротивление велико**: для равновесия под уклоном 6.35° нужна либо эквивалентная вязкость
  1.3–3 Па·с (ламинарно), либо коэффициент трения Дарси 0.12–0.2 (турбулентно; это шероховатость
  15–45 мм — сравнима с глубиной, нереально). Для чистого жидкого шлака на гладкой меди ожидались бы
  скорости в 2–3 раза выше. Вывод: стенки — шероховатый гарнисаж/корка, шлак частично
  закристаллизован (вязкопластичен), плюс тормозит неподвижная корка у краёв зеркала.
- **Форма поперечного профиля скорости** u_s(r)/u_ось (сглажено окном PIV, как измерение):

  | r, мм | 3 | 18 | 24 | 45 | 65 | 86 |
  |---|---|---|---|---|---|---|
  | измерено, 21:04 | 1.00 | 0.99 | 0.99 | 0.93 | 0.80 | 0.41 |
  | ламинарный ньютоновский (точное решение) | 1.00 | 0.96 | 0.94 | 0.79 | 0.57 | 0.30 |
  | турбулентный, u ~ d^(2/3) | 1.00 | 0.98 | 0.98 | 0.91 | 0.79 | 0.59 |

  Профиль площе ламинарного — так ведёт себя и турбулентный поток, и вязкопластичный с
  «пробкой» в ядре (что согласуется с высоким сопротивлением).

## Поправки к расходу

Исходное: Q₀ = A(h) · u_s,ось. Поправленное:

    G = ρ_см · Q,   Q = C · A_эфф(h) · u_s,ось,   C = k_⊥ · k_v

1. **k_⊥ — поперечная неравномерность скорости поверхности**:
   k_⊥ = ∫u_s(x)·d(x)dx / (A·u_s,ось). Измеряется по профилю, 0.84–0.87 (в расчёте уже есть).
2. **k_v — профиль по глубине** (средняя по вертикали / поверхностная):
   - ламинарный ньютоновский: 0.665–0.670 — точное решение для этого сечения, не зависит от
     уровня (50–120 мм) и гарнисажа; полный C = 0.49–0.50;
   - вязкопластичный (пробка в ядре): 0.7–0.9;
   - турбулентный: 0.85–0.9; полный C = 0.72–0.76.
   По форме измеренного профиля C ближе к верхней части: **0.6–0.75**. k_v можно выбирать
   по серии автоматически: по тому, к какой модели ближе измеренный профиль.
3. **Гарнисаж на меди, толщина δ**: зеркало в кадре ограничено гарнисажем, а не медью; уровень
   по медному профилю занижен. δ = 10 мм: уровень +16–21 мм, A +12–18%; δ = 20 мм: A +30–44%.
   Нужен замер δ (после слива, по пустому жёлобу).
4. **Заход корки на зеркало (25 мм)**: главный источник погрешности. ±10 мм → уровень ±11–19 мм,
   A −28…+39%. Уточнить по снимкам корки/сколам или калибровочным сливам.
5. **Плотность**: 3480–3515 вместо 3400 (+2.5–3.5%), эмульсия штейна +0.3…+1.5% (до +3.5% при
   высоком Ni в шлаке); газовая пористость (если есть) — в минус.
6. **Масштаб на высоте зеркала**: калибровка по дну, зеркало на 50–100 мм ближе к камере — масштаб
   −1.5…−2%, Q −2…−3%. Градиент масштаба вдоль кадра ±2% (0.517–0.548 мм/px).
7. **Осреднение во времени**: Q считать по каждой серии и усреднять потом (волны, Fr ≈ 2).
8. **Температура**: смена вязкости на ±25 K меняет её в 0.75–1.3 раза; к концу слива, по мере
   остывания, режим смещается к ламинарному, и C падает. Отдельной поправкой не нужна, если k_v
   выбирается по форме профиля (п. 2).
9. **Итоговая калибровка — по массе**: интеграл ρ·Q за слив против взвешенной массы.
   Проверка по 19.09 (46 мин записи, без гарнисажа, ρ 3400–3500): C = 0.49 → 102–105 т,
   C = 0.60 → 125–129 т, C = 0.73 → 152–157 т. С учётом начала слива до 18:40 это совместимо
   с 160–180 т при C ≈ 0.65–0.75 — если эти тонны относятся к этому сливу.
